# TaskSuite_E — 电赛 E 题任务 1–6 统一套件（K230 触控选任务）

## 烧录 / 运行

1. Arduino 烧录 `TaskSuite_E.ino`
2. CanMV 运行 `k230/suite_ui.py`（需带屏触控；逻辑依赖同目录 `game_vision.py`）

屏：WonderMK 课程标准 **`Display.JD9852` 320×240** + **`Pin(25)` 背光**；触控 `TOUCH(0)`（CST328）。

## 主界面（2×3）

```text
1  2  3
4  5  6
```

| 任务 | 内容 | 操作 |
|------|------|------|
| 1 | 黄子→格5 | 触控 START |
| 2 | 2黄2蓝指定格 | 九宫格依次点 Y1/Y2/B1/B2 → START |
| 3 | 同2，ESP 自动切旋转盘标定（YAW=45°） | 同左 |
| 4 | 机先手对弈 | START 开局；**KEY2** 人下完；终局触控 **NEXT GAME** |
| 5 | 人先手不败 | 同4（人先下黄） |
| 6 | 对弈+挪子复位 | 同4；挪黄子后 KEY2 会复位 |

**返回菜单**：各页 BACK → 臂回俯视。  
**对局中 KEY1 不再开新局**，终局须触控「再来一局」。

## I2C（地址 0x5F，mem≥64）

| 偏移 | 含义 |
|------|------|
| `0x00..0x18` | 对局/抓放（同 Task08） |
| `0x20` | TASK 1..6 |
| `0x21` | UI_CMD：1选任务 2开始 3再来一局 4返回 |
| `0x22` | UI_ARG |
| `0x23` | 序列长度 |
| `0x24..` | 每步 color,slot,cell ×4 |
| `0x30` | ESP_STATE |
| `0x31` | UI_SEQ |

## 主要文件

| 文件 | 作用 |
|------|------|
| `SuiteI2C.*` | 协议 |
| `system_task_handle.cpp` | 任务调度 |
| `CamPickRunner.*` | 抓放/格→格 |

## 按键 / 触控对照

| 动作 | 方式 |
|------|------|
| 选任务 1–6 | 主菜单触控 |
| 任务1/2/3 开始 | 触控 START |
| 任务2/3 配格 | 九宫格依次点 4 格；CLEAR 重配 |
| 任务4/5/6 开局 | 触控 START |
| 人下完 | **KEY2**（BOOT） |
| 再来一局 | 终局触控 NEXT GAME（KEY1 无效） |
| 回主菜单 | 触控 BACK（臂回俯视） |

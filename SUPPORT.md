# Support

## Before asking for help

1. Read the [Development and Operation Guide](docs/DEVELOPMENT.md).
2. Search existing Issues and the task-specific README.
3. Reproduce with Mock, offline input, or plan-only mode when possible.
4. Run `python tools/check_repo.py` and `python -m pytest -q`.

## Where to ask

- Reproducible software defect: open a **Bug report**.
- Focused improvement: open a **Feature request**.
- Sensitive security or unsafe-control issue: follow [SECURITY.md](SECURITY.md), not a public Issue.

This is a competition and portfolio project, not a commercial support service. Help is best-effort. Maintainers cannot validate another machine's wiring, calibration, motion envelope, serial mapping, or electrical safety remotely.

Never post credentials, full device serial identifiers, personal information, private network details, or instructions that energize hardware without the project's safety gates.

# 开源发布检查清单

本清单面向首次将仓库设为公开可见。它不改变源码，也不替代许可证或第三方合规审核。

## 发布前必须完成

- [x] **选择开源许可证**：原创代码和文档采用 MIT License，版权人标注为 `fear66six`。
- [ ] **确认第三方再分发条件**：重点检查 `firmware/**/cmsis/` 中 ARM/ST 文件、NexArm 厂商 SDK，以及 `TaskSuite_E/` 的来源与授权。
- [ ] **补充本人贡献范围**：在 `docs/PORTFOLIO.md` 中只写真实负责的模块，区分团队成果与个人贡献。
- [ ] **补充奖项佐证**：如适合公开，可在 `assets/showcase/` 放置脱敏证书或官方结果链接；否则保留“项目负责人提供”的说明。
- [ ] **检查隐私与设备标识**：复核串口 by-id、局域网地址、用户名、绝对路径、日志、照片背景和 EXIF。
- [ ] **清理已追踪生成物**：`.gitignore` 不会自动移除已纳入 Git 的文件；确认不需要后再从版本控制中移除 `runs/`、`output/`、`logs/`、`tmp/`、`backup/` 和固件构建日志。
- [ ] **确认历史记录**：即使当前文件已删除，Git 历史仍可能包含设备信息或第三方文件；必要时在公开前重写历史。

- [ ] GitHub Topics，例如 `computer-vision`、`robotics`、`embedded-systems`、`jetson`、`stm32`；
- [ ] Issue / Pull Request 模板和持续集成；

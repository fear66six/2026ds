# Q1 A4 标定与锁定指南

## 默认自动锁定

启动实时模式后，程序连续收集有效纸张四角。至少 15 帧通过凸性、面积、A4 长宽比、边长和透视变换检查后，去除异常值并对四角取中位数，然后冻结纸框。

纸框未锁定时状态保持 `WAIT`，检测失败不会退化为整张画面。固定相机运行期间不会按固定时间无条件替换纸框。

## 手工标定

在实时窗口按 `C`，依次点击：

1. TL：左上
2. TR：右上
3. BR：右下
4. BL：左下

Enter 接受，Backspace 撤销最后一点，Esc 取消。通过校验后保存到：

```text
2026E/config/q1_paper_calibration.json
```

文件保存归一化四角，分辨率改变时会按当前画面尺寸恢复；它是当前机位的配置，不代表摄像头移动后仍有效。

## 快捷键

- `C`：手工重新标定并保存
- `R`：清除当前锁定，重新执行自动检测
- `L`：锁定或解锁当前纸框
- `S`：保存原图、掩膜、候选图和 JSON 诊断

## 画面标记

- 黄色：锁定/当前采用的 A4 四边形
- 青色：经过厘米内缩和像素腐蚀的 Q1 上半区安全 ROI
- 绿色：四模板选择器最终选中的候选
- 红色：拒绝候选及首个拒绝原因

## 重新标定条件

相机、A4、支架或焦距发生变化，或者黄色四边形不再贴合真实纸边时，按 `R` 重新自动检测；自动检测不稳定时使用 `C`。不要通过放宽 ROI 或反光阈值来补偿错误纸框。

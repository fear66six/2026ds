# Q1 实时检测修复报告

日期：2026-07-29

## 实现结果

- 纸框：真实四边形；支持手工标定和至少 15 帧中位数自动锁定
- 安全 ROI：A4 厘米坐标中左右/上边内缩 0.8 cm，分界线向上内缩 0.4 cm，再腐蚀 3 px
- 边界过滤：完整轮廓安全区覆盖率至少 0.98，并拒绝接触边界、跨分界线和 A4 外候选
- 实时超大轮廓：超过 30 cm² 拒绝，不调用 watershed 或旧拆分函数
- 四片选择：枚举候选四元组与 4! 模板排列，综合面积、顶点、solidity、compactness、灰度、边界距离和置信度
- READY：四个模板关系一致、中心变化小于 0.5 cm、面积变化小于 15%，连续三次才成立
- 显示：当前采集帧持续刷新；历史检测结果仅以结构化坐标轻量叠加
- 诊断：S 键保存原图、纸框掩膜、安全 ROI、原始二值图、全部候选、选择结果和 JSON

## 未做的实机声明

本轮没有打开摄像头，因此 Capture/Display/Detect FPS 均未重新实测。用户此前观察到的约 11 FPS 只能作为修改前现象，不能当作修复后结果。

## 实机验收步骤

1. 固定相机和 A4，启动 640×480@30 MJPG DSHOW。
2. 等待自动锁定；黄色纸框必须贴合 A4，青色安全区不得越出上半区。
3. 放置真实四片，确认额外反光区域为红色并显示拒绝原因。
4. 等待 `STABILIZING 1/3`、`2/3`、`READY`。
5. 按 S 保存诊断包，并记录 CAP、DISPLAY、DETECT FPS、DETECT MS、RESULT AGE。
6. DSHOW 不达标时，用相同场景和参数比较 MSMF。

该流程只做视觉验证，不需要连接机械臂、STM32、MOSFET 或电磁铁。

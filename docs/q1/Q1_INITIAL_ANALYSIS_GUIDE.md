# Q1 初始高清分析指南

## 抓图

SPACE 后等待配置化稳定时间，清除旧帧并抓取8帧。每帧记录：

- Laplacian清晰度
- 平均亮度
- 高光占比
- 暗区占比
- 方向梯度运动模糊辅助指标

严重模糊、过曝或欠曝帧被拒绝，剩余帧中选择最清晰者。失败会显示明确原因。

## 标定与几何

按 C 依次点击 TL、TR、BR、BL。标定保存原始分辨率、像素四角、归一化四角、方向、时间、目标校正尺寸和校验结果。分辨率宽高比变化超过1%时要求重新标定。

正式分析流程：

```text
高清原图 → 固定四角 → warpPerspective
→ A4上半区安全ROI → 完整候选轮廓
→ 粗顶点 → 分边 → robust fitLine → 相邻线求交
→ 毫米边长/内角/面积/残差
→ P1/P2/P3/P4全局一一匹配
```

要求最终恰好四个有效碎片、一个三角形和三个四边形。纸外、跨分界线、接触ROI边缘、被裁切和超大反光轮廓均不能进入计划。

# 故障排查

所有排查先执行安全停机：停止机械臂、保持电磁铁关闭，必要时切断负载电源。以下顺序避免用更危险的动作掩盖根因。

## 常见问题

| 现象 | 可能原因 | 检查顺序与处理 | 立即停止条件 |
|---|---|---|---|
| Bash 显示 `PING: command not found` | `PING` 是 STM32 串口协议，不是 Linux 命令 | 不在 shell 直接输入；通过当前 Python 驱动调用 `magnet.ping()`，或使用明确配置的串口工具 | 无 |
| ATK 显示为 `/dev/ttyACM0` | Linux 驱动枚举名称可变 | 用 `ls -l /dev/serial/by-id/` 人工核对；生产配置使用已确认的 `by-id`；不要永久硬编码 tty 名称 | 多个候选无法唯一确认时停止 |
| Windows 显示未知 STM32 USB 设备 | 当前固件未实现 USB CDC；STM32 Micro-USB 数据线接 PA11/PA12 也不会提供本协议 | 使用 ATK 的 USB 设备和 USART1；确认 BOOT0=0、复位、ATK COM/串口正常 | USB 口/芯片异常发热 |
| PING 超时或回复错误 | 端口错误/占用、BOOT0 未恢复、8E1 与 8N1 混淆、TX/RX 反接、未共地、STM32/ATK 掉线 | 先 `MAGNET_OFF`/切断负载；确认 BOOT0=0；应用串口为 115200 8N1；检查端口所有者、TX→PA10、RX←PA9、GND；复位后只测 PING | 线缆或模块发热、供电不稳 |
| `FAULT=1` | RX 环形溢出、USART ORE/NE/FE/PE，或命令行过长 | 停止发送；检查 115200 8N1、线缆、共地和发送速率；发送 `MAGNET_OFF` 清故障后再次只测 PING/状态 | 故障反复出现或状态不可信 |
| `ERR invalid_timeout` | 缺参数、非整数、范围不在 50–500 | 修正为 `MAGNET_ON <decimal_ms>`；不要反复试错启用 | 上层生成了不受控参数时停止状态机 |
| `ERR unknown_command` | 名称/空格/大小写不匹配 | 对照 [协议](STM32_UART_PROTOCOL.md)；注意该错误会强制关闭 | 无 |
| `ERR line_too_long` / `ERR rx_overflow` | 单行超过 63 字符、发送过快或 UART 错误 | 停止发送，等一行结束；核对串口参数和上层并发；`MAGNET_OFF` 后重新握手 | 重复发生 |
| MOSFET 指示灯不亮 | 默认状态本来为关；PB12 未到 IN/PWM、未共地、模块指示灯依赖负载电源、模块逻辑不同 | 不先延长通电；核对 PB12、控制地、模块丝印和负载侧电源；用空载测量方案单独验证 | 接线不明、模块发热 |
| MOSFET 灯亮但电磁铁不吸 | 降压无输出/压降、负载端接错、端子未夹住铜线、线圈断路、MOSFET能力不足 | 切断负载电源；依次测降压空载/带载、MOSFET输入与负载端、端子和线圈电阻；按实物资料重接 | 过热、异味、异常大电流 |
| 电磁铁吸住但不松 | 仍通电，或已断电但剩磁/大面积贴合 | 先 `MAGNET_OFF`，再 `GET_STATUS`；若条件允许从负载电源侧判断是否仍通电；确认关闭后使用薄非磁垫片、等待、受限侧移和视觉检查 | 状态无法确认、工件卡住或机械碰撞风险 |
| `MAGNET=0` 但工件仍粘着 | 软件状态不代表物理释放 | 保持关闭；等待标定时间；受限侧移 2–5 mm 候选范围并视觉确认；失败进入人工处理 | 达到恢复次数/位移上限 |
| 端口权限错误 | Jetson 用户无串口设备权限 | 不用提权脚本绕过；核对设备节点权限、用户组和部署规则，重新登录后再测安全命令 | 权限来源不清或需要改系统配置时停止并审批 |
| 端口被占用 | 多个程序/进程打开同一串口 | 找到占用者，正常退出；不要强杀未知进程；确保单进程所有权 | 无法确认所有者 |
| 降压模块发热或电池保护触发 | 过流、短路、效率/散热不足、输入或极性错误 | 立即断负载；检查极性、短路、额定值、线圈电阻和带载电压；冷却并查明原因后才恢复 | 任意过热、异味、烟雾 |

## “不松开”的判别顺序

```text
停止机械臂
  → MAGNET_OFF / EMERGENCY_OFF
  → GET_STATUS
  → 若 MAGNET=1 或通信失败：切断负载电源，停止自动流程
  → 若 MAGNET=0：仍不能断定无电流
  → 在安全条件下确认 MOSFET/负载电源状态
  → 确认断电后仍粘连：按剩磁释放恢复流程
```

不要通过重新长时间通电“试一试”，也不要在未确认周围工件与碰撞空间时甩动机械臂。
